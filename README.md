# 🏥 Hospital Management System

## 📌 Overview
This project is a backend Hospital Management System developed using Spring Boot 3.2 and MySQL.

It provides secure REST APIs for managing:
- Patients
- Doctors
- Admin operations
- Doctor availability scheduling

---

## 🚀 Tech Stack

- Java 17
- Spring Boot 3
- Spring Security 6
- JWT Authentication
- Spring Data JPA
- MySQL
- Maven

---

## 🔐 Features

### 1️⃣ Authentication & Authorization
- Patient Registration
- Doctor Registration
- Login with JWT
- BCrypt password encryption
- Role-based access control (PATIENT / DOCTOR / ADMIN)

---

### 2️⃣ Admin Module
- View registered patients
- Pagination support
- City-based filtering

---

### 3️⃣ Doctor Module
- Add/Update professional profile
- List doctors with filtering
- View doctor details

---

### 4️⃣ Availability Module
- Add availability slots
- Overlapping time validation
- Slot generation logic
- View slots by date
